| 1 | 2026-08-02 | bootstrap | Scoped the first phase to CVRP100 because the repository already contains a matching seed-conditioned checkpoint and the local machine has no GPU. H2 (Fisher/transport) is gated on positive H0/H1 evidence. |

This run validates the pipeline only; its sample size is intentionally non-inferential. |
| 3 | 2026-08-03 | infrastructure | Pushed source commit `5f40ebb` to `Tarseus/NDS:agent/crossdist-latent-transfer`. Because g51 temporarily could not resolve GitHub, deployed an object-complete, `git fsck`-verified bundle and cloned it at the same SHA. Remote tests passed 10/10. |
| 4 | 2026-08-03 | inner-loop | Completed `crossdist-code-transfer-20260803-072321` on g51 GPU 3: 64 instances/distribution, 32 fixed codes, 4 replicas. Split-half code-rank reliability passed on 6/6 distributions (median Spearman 0.294–0.387; all bootstrap lower bounds positive), rejecting H0. Uniform-only feature kNN met the locked OOD criterion on only 1/5 targets and had significant negative transfer on `x_cluster_center`, so locked H1 was rejected and full-search was not started. |
| 5 | 2026-08-03 | outer-loop | Exploratory leave-one-distribution-out reuse of the same tensor selected a multi-source mean code with positive raw gain on 6/6 held-out targets (+0.003740 to +0.009304). This is post-hoc steering evidence only. Registered H1b and locked a fresh-instance confirmation before implementing its analyzer. |
| 6 | 2026-08-03 | inner-loop | Independent run `multisource-confirm-20260803-073235` used fresh instance seed `20260804` and confirmed H1b on 6/6 held-out distributions. Relative one-step gains were +21.4% to +45.3%; every 95% bootstrap lower bound was positive and no target was significantly negative. The corner/quad target changed from uniform-only gain -0.003927 to multi-source gain +0.012654. Result branch `df393a1` records source `7e0b8e8` and completed state. |
| 7 | 2026-08-03 | outer-loop | Promoted H1b to supported. Registered H3 and locked a fresh-seed, equal-rollout, 200-iteration full-LNS experiment before implementation. |
| 8 | 2026-08-03 | inner-loop | Run `full-lns-transfer-20260803-074321` rejected H3. Multi-source fixed-code final advantage over random fixed passed on 0/6 distributions, anytime AUC passed on 0/6, and 4/6 distributions had significant primary harm. Multi-source still improved initial cost by 9.82%–23.19%, but was 0.28%–1.67% worse than random fixed at iteration 200 and 0.64%–2.05% worse than the 32-code panel. Result branch `1c0c177` records source `521dc75`. |
| 9 | 2026-08-03 | outer-loop | Checkpoint analysis showed the static code was already behind on 3/6 targets after one iteration. Diagnosed an objective mismatch: calibration ranks mean reward with four replicas, whereas full LNS exploits the best tail among 32 rollouts. Registered H4: an informed top-8 portfolio with four replicas per code under the same total budget. |
| 10 | 2026-08-03 | failure | `portfolio-lns-transfer-20260803-075100` exited before computation because one array allocation retained the removed `STRATEGIES` constant. No scientific result was produced. Published logs with failed state on result commit `3c66af4`, fixed the reference to dynamic `strategies`, and added local/remote CLI smoke plus 16 passing tests. |
| 11 | 2026-08-03 | inner-loop | Corrected run `portfolio-lns-transfer-20260803-075441` rejected H4 on fresh seed `20260809`. Top-8 versus the 32-code panel passed final cost on 0/6 and anytime AUC on 0/6; every distribution had significant harm on at least one primary metric. Top-8 final cost was 0.15%-0.96% worse than the panel, although it was slightly better than random fixed on 5/6 targets. Completed result branch `7b30a2f` records source `d3090af`. |
| 12 | 2026-08-03 | outer-loop | Concluded that static cross-instance latent selection is not a sufficient automatic-generalization mechanism for full LNS. The supported contribution is a cross-domain prior/screening signal. Registered H5 as the next direction: incumbent-conditioned online allocation over the full panel, with explicit diversity and safe fallback; deferred Fisher geometry until this simpler dynamic baseline is tested. |
